This post contains some frequently used AWS commands.

- List aws profiles:

  ```bash
  aws configure list-profiles
  ```

- View a specific aws profile:

  ```bash
  aws configure list --profile [profile name]
  ```

- Update region for an aws profile:

  ```bash
  aws configure set region [region code] --profile [profile name]
  ```

- Get current account:

  ```bash
  aws sts get-caller-identity
  ```
